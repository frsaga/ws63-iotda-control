# WS63 IoTDA Control Samples

Application-level WS63/OpenHarmony coursework for motor and LED control, MQTT commands and property reporting. Files include `MOTOR.c`, `STAR_LED.c`, `mqtt_cloud.c` and `BUILD.gn`.

Integrate these sources into an appropriate WS63 SDK project. The original SDK and device/cloud credentials are not bundled. Configure your own Wi-Fi, device identity, password and broker endpoint locally; the old broker address was replaced with a loopback placeholder. This snapshot was not flashed to hardware for publication.
